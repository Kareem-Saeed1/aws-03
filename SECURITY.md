# Security policy

Do not include credentials, state files, personal data or exploit details in public issues.

If private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** option. If it is unavailable, open an issue asking the maintainer for a private reporting channel without including vulnerability details.

Include affected versions, reproduction steps and the impact in the private report. This project has no guaranteed security response SLA.

See [security controls and production hardening](docs/SECURITY.md) for the implementation's limits.
