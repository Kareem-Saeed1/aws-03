# Start here

The [README](README.md) describes the solution and includes the architecture diagram.

To deploy it:

1. Prepare the account, permissions, DNS names and notification email using [prerequisites](docs/PREREQUISITES.md).
2. Follow the [deployment runbook](docs/DEPLOYMENT.md), including database initialization and removal of bootstrap permissions.
3. Complete the [acceptance tests](docs/TESTING.md) and record actual results under [evidence](docs/evidence/).
4. Follow [cleanup](docs/COSTS-AND-CLEANUP.md) when the exercise is complete.

The repository is [Kareem-Saeed1/aws-03](https://github.com/Kareem-Saeed1/aws-03). Deployment and live acceptance testing are still pending.
